# 已确认的产品约束

2026-11-14 用户确认，取代最初决策稿中的未决状态。

| 项目 | 确认内容 |
| --- | --- |
| 平台 | Windows 10+；Android 12+ 手机和平板。手写笔设备细节尚未提供。 |
| 输入法 | 仅在无限记内使用，英文 QWERTY（标准英文键位）与中文/英语语音。 |
| 语音 | 同时提供离线和私人服务器两种模式。当前用 Vosk/WASM 实现离线入口、faster-whisper 实现服务端入口；具体模型及效果尚待设备验收。 |
| 外置代码 | 原生壳/权限桥接留安装包，业务资源、模型和数据目标放用户目录；允许私有运行缓存。 |
| 云端 | 用户有域名和 ECS；暂按 2 vCPU / 4 GB 内存 / 80 GB 硬盘设计，具体系统和公网部署信息未提供。 |
| 协作 | 多人实时协作延后，先做个人跨设备同步。 |
| 分发 | 所有自写源码在 YKZStudio/InfinityNotes；优先 GitHub Releases（发行版），暂不上架应用商店。 |
| 对齐 | 以当前最新无边记常规能力为目标；暂不包含 AI 扩展和苹果原始格式互通。 |

第一项原回复“可以考虑支持”之后内容缺失，暂不推测额外平台。

首次启动继续让每个用户选择主题、存储位置和是否启用内置输入，禁止默认申请麦克风。语音服务器模式明确说明录音会上传，取消编辑不上传未提交录音。

原型语音模型暂保存在本机浏览器数据库与推理库缓存中，尚未实现大模型文件向自选原生目录的完整迁移/恢复。这是当前实现差距，不能视为外置模型目标已验收。

最新无边记常规功能清单仍见原始规格的矩阵，表格、图表、动态连线、富文本、完整媒体/文件预览、PDF 导出、回收站及笔输入等均要继续完成。当前基础画板不代表“全部功能”完成。
