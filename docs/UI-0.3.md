# 0.3 界面与手机适配

本轮承接 2026-11-14 的界面整改要求：重设计界面与应用图标，避免 Android 通知栏/系统导航区遮挡，改善手机操作。没有把基础画板宣称为完整无边记。

## 设计与操作

- 浅色点阵画布、收敛的灰白侧栏、橙金色主题和独立绘制的无限笔迹图标；主题色仍可自行修改，已有设置保持有效。
- 悬浮工具栏保留选择、漫游、便笺、文字、画笔；形状、箭头、图片和链接归入插入面板。
- 手机点击对象先显示简短操作条，按属性按钮再展开宽高、颜色、旋转、复制/删除等设置。
- 小屏幕的重做、导出、同步和设置均可从右上角更多操作进入。
- 看板抽屉提供遮罩、关闭按钮、返回焦点及键盘焦点循环。关闭后停止接收触控和键盘焦点。
- 选择模式下单指拖动空白处即可移动画布；双指移动/缩放可在其他工具启用时使用。第二根手指落下时撤销此次临时笔画或移动，不留下意外对象。点选本身不占用撤销记录。

## 安全区

网页层使用 `env(safe-area-inset-*)`（系统安全区变量），原生 Android 层另读取系统栏和屏幕刘海边距。根据网页视图在窗口内的位置计算实际重叠部分，防止系统已预留空间时重复增加边距。使用布局观察而不替换框架自己的系统边距监听器。

前端取两种来源的较大值，分别约束顶部操作、底部工具栏、侧边抽屉和对话框。横屏手机保持紧凑布局；系统栏图标颜色跟随应用的深浅色。文字编辑窗随可视高度调整，避免系统键盘弹出后底部按钮无法滚动到达。

此改动增加了原生接口，旧 APK（安卓安装包）仅热更新业务代码不能获得完整修复，需要安装新版。原生接口编译通过不能替代真机系统栏验收。

## 验证范围

`tests/browser-check.cjs` 保留首次设置、编辑、撤销、锁定、拖动、手绘、缩放、场景、键盘、同步、导出和重启恢复流程。`tests/mobile-check.cjs` 增加以下场景：

| 模拟窗口 | 检查 |
| --- | --- |
| 320 × 640 | 小屏工具触达、底部属性与导出 |
| 390 × 844，浅色/深色 | 顶部 32、底部 24 CSS 像素安全区及基本编辑 |
| 768 × 1024 | 竖屏平板的紧凑布局与触控 |
| 844 × 390 | 横屏手机，左 44、右 20、底部 18 CSS 像素安全区 |

原生边距在浏览器测试中使用模拟值。仍需在 Android 12+ 真机验证通知栏、三键导航/手势导航、横竖屏、系统键盘、文件夹授权和重启恢复。手写笔压感、橡皮擦、掌触抑制尚未实现，本轮只确认其后续范围。
