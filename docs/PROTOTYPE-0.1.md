# 无限记 · 开发原型 0.1

这是“无限记”的第一阶段源码：可启动的跨屏画板原型、个人同步服务、签名业务资源包开发工具，以及完整开发范围与待确认决策。

**当前不是 Windows 安装程序或 Android APK，也没有完成无边记的全部功能。** 本版通过本地浏览器运行，用于确认产品方向、编辑数据格式和客户端/服务端交互。原生客户端将在存储、输入法及发布方式确认后接入。

## 运行

只想查看原型，可以在解压后尝试用桌面浏览器双击打开 `preview.html`；它由同一份客户端源码生成，不含云服务。文件模式下的存储、语音和文件夹接口受浏览器限制，建议正式体验仍使用下方本地服务。该单文件预览同样尚未通过当前环境的浏览器实测。

需要 Python 3.10 或以上版本。普通画板和同步服务不依赖第三方 Python 包，也不需要安装 Node.js（JavaScript 运行环境）。

Windows：解压后双击 `start-windows.bat`，然后在 Microsoft Edge（微软浏览器）或 Chrome（谷歌浏览器）打开：

```text
http://127.0.0.1:8787
```

也可以在解压目录打开终端运行：

```powershell
py -3 server/app.py
```

Linux / macOS 测试环境：

```bash
python3 server/app.py
```

直接双击 `client/index.html` 不受支持，因为浏览器会限制本地 JavaScript 模块和存储接口；请通过上面的启动服务打开。

## 已实现

- 可平移、缩放的无限画布；双指缩放的事件处理代码已加入，尚待真机验证。
- 多看板、新建、重命名、内容搜索和删除；删除前确认。原型暂无回收站。
- 便笺条、文字、矩形、椭圆、箭头、手绘笔迹、图片和网页链接。
- 单对象移动、宽高调整、旋转、填充色、文字色、锁定、置顶、复制、删除。
- 撤销与重做，场景保存与跳转。
- 看板 JSON（结构化数据文件）导入导出、SVG（可缩放矢量图）导出、完整工作区备份。
- IndexedDB（浏览器本地数据库）自动保存；支持的桌面浏览器可选择文件夹保存工作区。
- 首次设置：存储、浅色/深色/跟随系统、主题色、减少透明效果、内置输入开关。
- 应用内英文 QWERTY（标准英文键位布局）26 键键盘，包含大写、退格、空格和换行。
- 中文/英文浏览器语音预览：手动开始、停止和转写。可能联网，未集成离线语音模型。
- 个人同步服务：密钥校验、看板上传/下载、持久化数据库、版本冲突拒绝覆盖。
- 业务资源包签名、验签、完整性校验、版本回退拒绝、服务端发布目录；**尚无客户端自动下载、激活和回滚**。

## 操作

1. 在底部选择便笺、文字或形状工具，然后轻点画布插入。
2. 双击对象或使用右侧“编辑内容”输入文字。
3. 拖动对象移动；按住空格拖动或选择“漫游”移动画布。
4. 滚轮缩放；使用左下角按钮保存当前视角为场景。
5. `Ctrl+Z` 撤销；`Ctrl+Shift+Z` 重做；`Delete` 删除未锁定对象。
6. 快捷键：V 选择、H 漫游、T 文字、N 便笺、P 画笔。
7. 右上角“导出”可保存当前看板或整个工作区。

手机布局可从“看板列表 → 设置 → 导出 / 备份”进入导出。原型尚待界面实测。

## 文件夹行为

浏览器默认把编辑内容保存在当前浏览器自己的本地数据库中。清除站点数据会删除这些内容，建议保留工作区备份。

支持 File System Access API（文件系统访问接口）的桌面浏览器可以选择一个文件夹。之后写入 `wuxianji-workspace.json`，其中包含看板、图片及设置，不包含服务访问密钥。浏览器重新启动后可能需要重新选择该文件夹授权。若选择的文件夹已有工作区，会先询问是否载入；未同意时不会覆盖。

**本版尚未把运行中的业务代码移到自选目录，也不能用浏览器文件夹选择替代 Android 原生授权。** 这部分见 `docs/开发规格与决策.md`。

## 启用个人同步

服务端需要至少 24 字符的访问密钥。请在自己的终端生成并设置，不要把真实密钥写进源码、发到聊天或提交到代码仓库。

Windows PowerShell 示例：

```powershell
# 此行仅打印新生成的本机密钥，请自行保管。
py -3 -c "import secrets; print(secrets.token_urlsafe(32))"
$env:WUJI_TOKEN = "在这里填入自己刚生成的密钥"
py -3 server/app.py --data "D:\WuxianjiServerData"
```

在客户端设置中填入相同密钥。服务地址留空使用当前服务；点击“云端同步”上传当前看板，设置中的“下载云端看板”可恢复到另一设备。本版为**手动快照同步**，不是实时协作或自动双向同步。上传发生冲突时可下载为副本，本机版本会保留。

本地启动默认只监听 `127.0.0.1`。服务数据默认保存在用户目录的 `WuxianjiPrototypeData` 中。修改 `--data` 可以选择其他目录。

远程部署方案尚未选定，也没有在公网部署。后续需要配置 HTTPS（加密连接）、适当的域名/代理、账号隔离、备份和上传配额。当前共享密钥对应一个私人工作区，不适合多用户正式服务。若确需允许另一个客户端来源，可通过 `WUJI_ALLOWED_ORIGINS` 配置精确来源白名单，不使用通配符。

## 更新包开发工具

仅使用资源包工具时需要 `cryptography`（密码学库）：

```bash
python3 -m pip install cryptography
python3 tools/release.py keygen --private /安全位置/private.pem --public public.pem
python3 tools/release.py build --source client --private /安全位置/private.pem --out update.zip --version 1
python3 tools/release.py verify --archive update.zip --public public.pem --current-version 0
python3 tools/release.py publish --archive update.zip --public public.pem --current-version 0 --destination /服务数据目录/releases
```

Windows 可将 `python3` 替换为 `py -3`。私钥保留在自己的安全位置；正式客户端只内置公钥。以上生成和发布的是可验证资源包，**不会自动让当前客户端热更新**。服务提供 `/api/releases/latest` 和 `/api/releases/<摘要>.zip` 下载接口，待原生外壳接入后才会启用远程更新闭环。
