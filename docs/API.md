# 原型服务接口

普通服务只使用 Python 标准库。JSON（结构化数据）使用 UTF-8（字符编码）。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/health` | 版本、同步开关；不含私密内容 |
| GET | `/api/boards` | 看板摘要列表，需身份校验 |
| GET | `/api/boards/{id}` | `{revision, board}`，需身份校验 |
| PUT | `/api/boards/{id}` | 完整看板，需身份校验与 `If-Match` 预期版本 |
| POST | `/api/speech/transcribe` | 可选服务器语音，WAV 单声道 16 位，不超过 60 秒；需身份校验 |
| GET | `/api/releases/latest` | 已发布资源包清单；无更新时 404 |
| GET | `/api/releases/{sha256}.zip` | 资源包下载；仅固定摘要名称 |

身份校验头为 `Authorization: Bearer <WUJI_TOKEN>`，密钥长度至少 24 字符。所有使用同一密钥的设备共享同一个私人工作区；没有多用户隔离。

`If-Match: 0` 创建新看板；已有看板使用上次确认的 revision（修订号）。成功返回 `{revision: 下一版本}`；过期版本返回 409，不覆盖当前数据。缺少预期版本返回 428。修改看板标识不等于修改已有云端看板；本原型未实现云端删除。

上传体上限 12 MB；完整工作区本地导入上限 32 MB。单图片上限 5 MB；看板最多 5000 对象与 100 场景。这些是原型资源边界，不是正式产品配额承诺。

看板结构见 `client/core.mjs` 中的 `board`、`node` 和 `validateBoard`。正式版应提供共享的严格模式定义与迁移协议，避免客户端和服务端验证规则漂移。

服务绑定地址默认 `127.0.0.1`。如需远程客户端访问，先确定部署和加密连接方案，再配置监听与反向代理；不要把开发访问密钥作为公开账号系统。

正式客户端更新器必须内置可信公钥，对清单及资源逐一校验；不能只依赖服务器返回的摘要或 HTTPS。客户端还需保存已激活的单调发布序号、管理双版本指针和恢复数据迁移。原生预览工程已接入暂存、验签、启动确认和回退代码，仍需原生构建及真机闭环验收；普通浏览器页面不执行更新包。
