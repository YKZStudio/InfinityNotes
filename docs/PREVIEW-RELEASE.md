无限记开发预览，面向 Windows 10+ 与 Android 12+。

此版本用于验证原生窗口、文件夹授权、基础画板与更新流程。完整无边记功能对齐仍在开发；离线/服务器语音需要自行配置模型及服务，识别效果与设备兼容性尚待验收。

Windows 安装程序暂未配置代码签名。Android 包采用调试签名，仅用于临时测试；后续换为正式签名时可能需要卸载重装，请先导出工作区。不要把调试签名作为长期升级身份。

若构建时没有设置更新公钥，界面会明确提示热更新未配置，不接受任意网络代码包。该状态不是热更新已正式启用。

请保留外部工作目录与备份，遇到问题可在本仓库 Issues（问题反馈）提交设备型号、系统版本和复现步骤，不要上传访问密钥或私人笔记。
